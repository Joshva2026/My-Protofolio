## 📂 Customization & Asset Asset Placeholders

All personal information and links are centralized in `src/data/portfolioData.js`.

### 1. Update Profile & Social Links
Edit `src/data/portfolioData.js`:
- `email`: Your actual email address
- `github`: Your GitHub profile link
- `linkedin`: Your LinkedIn profile link

### 2. Update Image Placeholders
Drop your image files into these folders:
- **Profile Photo**: `public/assets/profile/avatar.jpg`
- **Project Screenshots**:
  - `public/assets/projects/leaf-disease.jpg`
  - `public/assets/projects/resume-builder.jpg`
  - `public/assets/projects/iot-car.jpg`
- **Certificates**:
  - `public/assets/certificates/cert1.jpg`
  - `public/assets/certificates/cert2.jpg`

### 3. Add Resume PDF
Save your resume file as `resume.pdf` in the `public/` directory:
`public/resume.pdf`
